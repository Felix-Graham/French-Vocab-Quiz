# French Vocabulary Quiz

A terminal-based French vocabulary quiz written in Python.

## Features

- **Two quiz modes** — Traditional (type the answer) or Multiple Choice
- **Three session lengths** — Continuous, set number of questions, or maximum (all loaded words)
- **File selection** — Load a single file or multiple vocabulary sets at once
- **Auto-update** — Pulls the latest changes from GitHub via `git pull`
- **Alias setup** — Register a short terminal command so you don't have to type the full path each time

## Requirements

- Python 3
- Git (for auto-update)

## Setup

Clone the repository and generate the config file. This only needs to be done once.

```bash
git clone https://github.com/Felix-Graham/French-Vocab-Quiz.git
cd French-Vocab-Quiz
```

If you are using Windows, find the folder which you have just downloaded, and find the install.bat inside of it.
Double click it to run it, setting up the quiz.

On Chrome OS, open a terminal and navigate using 'ls' (list files where you are) and 'cd' (change directory) commands. Then run the 
install.sh script with './install.sh'.

## Usage

Once the installation is complete, open a terminal (or power shell on windows) and type frenchQuiz to start.

### Menu

```bash
frenchQuiz
```

Opens the home menu with the following options:

| Key | Action |
|-----|--------|
| `s` | Start a quiz |
| `c` | Show terminal commands |
| `u` | Update the script |
| `i` | Settings (alias setup) |
| `q` | Quit |

### Terminal Commands

You can bypass the menu entirely by passing an argument directly:

```bash
python3 quiz.py all      # Start quiz using all vocabulary files
python3 quiz.py select   # Start quiz with file selection
python3 quiz.py load     # Generate config file
python3 quiz.py update   # Pull latest version from GitHub
python3 quiz.py start    # Open home menu
```

## Vocabulary Files

Vocabulary files are plain `.txt` files stored in a `vocab/` subdirectory. Files should follow the naming convention `vocab_X-Y.txt` (e.g. `vocab_1-1.txt`, `vocab_1-2.txt`) so they sort correctly in the file selection menu.

Each file should contain French/English word pairs, one per line, with the French word on even lines and the English translation on odd lines. The first two lines of each file are treated as a header and skipped.
